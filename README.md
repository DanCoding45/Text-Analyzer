# Text-Analyzer

This is a C program that analyzes text files and counts the number of lines, words, and characters in them. The program reads a file and outputs the statistics for lines, words, and characters in the file.

## Features

- Counts the number of **lines** in the file.
- Counts the number of **words** in the file.
- Counts the number of **characters** in the file (including whitespace).
- Supports reading any text file provided as input.

## Requirements

- A C compiler (e.g., GCC, Clang).
- A terminal or command-line interface.
